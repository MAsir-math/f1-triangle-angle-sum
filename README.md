# Triangle Angle Sum Lab

Classroom web app for 馬Sir教室, Form 1, *Junior Secondary Mathematics in Action* Book 1A §5.2, the angle sum of a triangle.

The page is for teacher projection and recap. It does not replace the paper tearing activity (Activity 5.1).

## Modes

- **A Tear and join** (`#tear`) — five locked triangles; tear the interior angles and fit them against a ruler, then name the angle they form before 180° is revealed.
- **B Appendix proof** (`#proof`) — teacher-controlled steps: draw △ABC, construct DE ∥ BC through A, identify alternate angles, and conclude that a + b + c = 180°.
- **C Find the unknown angle** — locked textbook items Example 5.3 (`#ex5.3`), Quick Practice 5.3 (`#qp5.3`), and Example 5.4 (`#ex5.4`). All three are available from the start.

Deep links for Mode A: `#tear-acute`, `#tear-right`, `#tear-obtuse`, `#tear-iso`, `#tear-equilateral`.

Student-facing text is in English. Traditional Chinese teacher notes can be toggled on. The page collects no student data.
